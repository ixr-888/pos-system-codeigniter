# Tasks for Today Management System

A simple task-management web application developed using CodeIgniter 4 and MySQL.

## Features

- View tasks scheduled for today
- View all tasks
- View a demo user profile
- View system and developer information
- Uses a MySQL relational database
- Uses CodeIgniter 4 MVC architecture
- Uses migrations and a database seeder

## Technologies Used

- PHP 8.2
- CodeIgniter 4
- MySQL
- XAMPP
- Composer
- Git and GitHub

## Database

Database name:

`tasks_management`

The system contains two main tables:

- `tasks`
- `users`

The database structure can be created using the CodeIgniter migrations.
